Mẹo lấy CSS Selector

1. Mở web bằng Google Chrome
2. Click chuột phải vào nút/ô nhập > Inspect (Kiểm tra)
3. Chuột phải vào dòng code bôi đen > Copy > Copy selector
4. Dán (Paste) đoạn mã đó vào ô CSS Selector.
Kéo thả nhiều field giống selector: ưu tiên nhập tên đang hiển thị của field, như Single, Number hoặc Lookup. Chỉ dùng số thứ tự nếu cả tên lẫn selector đều trùng.
